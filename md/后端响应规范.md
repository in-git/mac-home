# 后端响应规范

## 响应结构

统一JSON格式，共4个字段：

| 字段    | 类型   | 说明                     |
| ------- | ------ | ------------------------ |
| code    | Number | 状态码                   |
| msg     | String | 提示语                   |
| data    | Object | 返回数据（仅成功时返回） |
| traceId | String | 跟踪ID（排障用）         |

## 状态码

| code             | 说明                           |
| ---------------- | ------------------------------ |
| 200              | 成功                           |
| 401              | 未登录，token缺失或无效        |
| 403              | 无权限/无角色/账号被封禁       |
| 405              | 请求方法错误（GET/POST不匹配） |
| 415              | 参数校验或格式错误             |
| 500              | 服务器异常/数据操作异常        |
| 1011007、1011008 | token失效，需重新登录          |

## 前端处理

- code=200：正常处理data
- code!=200：提示msg内容
- code为401、1011007、1011008：跳转登录页

## 分页

请求参数：

| 参数    | 类型   | 默认 | 说明                |
| ------- | ------ | ---- | ------------------- |
| current | Number | 1    | 页码                |
| size    | Number | 20   | 每页条数（最大100） |

返回结构（data中）：

| 字段    | 类型   | 说明     |
| ------- | ------ | -------- |
| records | Array  | 数据列表 |
| total   | Number | 总条数   |
| current | Number | 当前页   |
| size    | Number | 每页条数 |
| pages   | Number | 总页数   |
