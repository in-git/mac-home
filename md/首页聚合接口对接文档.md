# 首页聚合接口对接文档

## 一、首页聚合 `homeAggregate`

首页首屏**头条区**（推荐轮播 + 排行榜 + 推荐宫格）的数据来源。
一次请求返回三组结果，替代原先「推荐 / 最新 / 最热」三次独立分页调用。

**接口**：`GET /api/public/site/homeAggregate`

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| size | Integer | 否 | `latest` / `hottest` 各自返回的条数，默认 5，范围 1-50（超出按 50 处理） |
| device | String | 否 | 当前用户设备：`PC` / `MOBILE` / `COMPATIBLE`；`PC` 返回「仅PC + 兼容」，`MOBILE` 返回「仅移动端 + 兼容」，不传则不限制设备 |

> `device` 是**分组**语义而非精确匹配；前端按运行环境自动判定并下发（`MOBILE` / `PC`）。

**响应 `data`**：`BizSiteHomeAggregateVo`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| latest | Array&lt;BizSitePublicVo&gt; | 最新发布的网页，按 `createTime` 倒序，同值时按 `orderNum` 升序 |
| hottest | Array&lt;BizSitePublicVo&gt; | 访问量最高的网页，按 `count` 倒序，同值时按 `createTime` 倒序 |
| recommends | Array&lt;BizSitePublicVo&gt; | **所有**推荐的网页，按 `orderNum` 升序、`createTime` 倒序 |

> `recommends` 不受 `size` 约束，固定返回全部推荐站点；
> 前端自行截取：宫格优先占前 3 条，其余进轮播（轮播上限 4 张）。

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "latest": [{ "id": "...", "name": "xxx", "count": 12, "createTime": "2026-09-01 10:00:00" }],
    "hottest": [{ "id": "...", "name": "yyy", "count": 9981 }],
    "recommends": [{ "id": "...", "name": "zzz", "recommend": true }]
  }
}
```

**前端实现**

| 位置 | 说明 |
| --- | --- |
| `src/api/site.ts` | `siteApi.getHomeAggregate()` + `SiteHomeAggregateParams` / `SiteHomeAggregate` 类型 |
| `src/agent/request/useSiteHomeAggregate.ts` | `useSiteHomeAggregate()` hook，负责拉取与字段兜底 |
| `src/views/HomeView/WebListPicker/index.tsx` | 头条区消费三组数据；宫格优先分配、轮播取剩余 |

## 二、常规列表（分页）

头条区**下方**的卡片网格，仍需分页拉取，且**排除推荐站点**（`recommend = false`），
避免与头条区重复展示同一个站点。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| identityId | String | 否 | 身份 ID |
| categoryId | String | 否 | 当前选中分类，级联包含其所有子分类；不传表示全部分类 |
| searchKey | String | 否 | 名称 / 描述 / 链接 模糊匹配 |
| keyword | String | 否 | 关键词精准匹配 |
| module | String | 否 | 所属模块 |
| recommend | Boolean | 否 | `true` 只看推荐、`false` 只看非推荐；**不传则返回全部** |
| device | String | 否 | `PC` / `MOBILE` / `COMPATIBLE` |
| current | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 20，上限 100 |
| sortField | String | 否 | `orderNum` / `count` / `createTime`，默认 `orderNum` |
| sortOrder | String | 否 | `ASCEND` / `DESCEND`，默认 `ASCEND` |

> `recommend = false` 会同时作用于首页与翻页（`loadMore`）两条链路；
> 若只在首页下发、翻页漏传，第 2 页起会把推荐站点重新捞回来，与首页口径矛盾。
