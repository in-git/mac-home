# 壁纸库公开接口对接文档（免登录）

> 对应后端：`vip.xiaonuo.biz.modular.wallpaper.controller.BizWallpaperPublicController`
> 路径前缀：`/public/wallpaper/**`，已在 `GlobalConfigure.NO_LOGIN_PATH_ARR`（即 `/public/**`）放行，**无需任何 token**，前端可直接访问。

## 一、壁纸库分页查询（免登录）

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/public/wallpaper/page` | 无（免登录） | 壁纸库分页查询，前端公开访问（C端/B端均可，无需登录） |

### 1. 请求参数（query / form 均可）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| current | Long | 否 | 当前页，默认 1 |
| size | Long | 否 | 每页条数，默认 10 |
| categoryTag | String | 否 | 分类筛选，如 `抽象` / `简约`，不传返回全部 |
| title | String | 否 | 标题模糊查询（文件名去扩展名） |

### 2. 响应示例

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "records": [
      {
        "id": "1900000000000000001",
        "title": "星空",
        "categoryTag": "抽象",
        "imageUrl": "/file/public/xxx.jpg",
        "thumbnailUrl": "/file/public/xxx_thumb.jpg",
        "fileSizeKb": 256
      }
    ],
    "total": 100,
    "current": 1,
    "size": 10,
    "pages": 10
  }
}
```

### 3. 前端调用示例

```js
import { baseRequest } from '@/utils/request'

const res = await baseRequest.get('/public/wallpaper/page', {
  params: { current: 1, size: 10, categoryTag: '抽象' }
})
// 无需任何 token，可直接 <img :src="record.imageUrl"> 使用
```

### 4. 说明

- `imageUrl` 为公开地址（`/public/**` 或 `/file/public/**`），前端可直接 `<img :src="url">`，无需携带 token。
- `thumbnailUrl` 为缩略图地址（公开地址，原图等比缩放到最长边 320px 后自动生成），同样可直接 `<img :src="url">` 使用，前端列表/瀑布流建议优先加载缩略图以提升性能。
- 该接口**不校验数据范围**，返回全部壁纸数据。
- 上传壁纸（入库）走**管理端** `POST /biz/wallpaper/upload`，仅超管可执行，见 B 端文档；上传时会自动生成缩略图并回填 `thumbnailUrl` 字段。

## 二、壁纸分类查询（免登录）

> 分类数据来源于系统「业务字典」，不写死在前端。父级字典 `dictValue = 壁纸分类`（category = BIZ），子项即各分类。

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/public/wallpaper/categoryList` | 无（免登录） | 获取壁纸分类列表，用于前端分类筛选 / 上传时选择分类 |

### 1. 请求参数

无。

### 2. 响应示例

```json
{
  "code": 200,
  "message": "成功",
  "data": [
    { "value": "抽象", "label": "抽象", "sortCode": 1 },
    { "value": "简约", "label": "简约", "sortCode": 2 }
  ]
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| value | String | 分类值（即 `dictValue`，也是壁纸 `categoryTag`），如 `抽象` / `简约` |
| label | String | 分类展示名称（即 `dictLabel`） |
| sortCode | Integer | 排序号，接口已按升序返回 |

### 3. 前端调用示例

```js
import bizWallpaperApi from '@/api/biz/bizWallpaperApi'

// 动态加载分类, 渲染 radio-group / select, 不写死
const categoryOptions = await bizWallpaperApi.bizWallpaperCategoryList()
// categoryOptions = [{ value: '抽象', label: '抽象', sortCode: 1 }, ...]
```

> 接口返回空数组（`[]`）表示字典未配置「壁纸分类」（父级 `dictValue = 壁纸分类`，category = BIZ）或其下无子项，需在业务字典中维护。

## 三、壁纸公开详情（免登录，返回高清图）

> 分页列表默认只返回 `thumbnailUrl`（缩略图，最长边 320px），适合网格/瀑布流快速渲染。  
> **点击查看后才调用本接口获取高清原图 `imageUrl`**，避免列表直接加载大图浪费流量。

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/public/wallpaper/detail?id={id}` | 无（免登录） | 根据壁纸 id 返回完整信息，含高清 `imageUrl` 与 `thumbnailUrl` |

### 1. 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | String | 是 | 壁纸主键 |

### 2. 响应示例

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "id": "1900000000000000001",
    "title": "星空",
    "categoryTag": "抽象",
    "imageUrl": "/file/public/xxx.jpg",
    "thumbnailUrl": "/file/public/xxx_thumb.jpg",
    "resolution": "1920x1080",
    "aspectRatio": "16:9",
    "fileSize": "256 KB",
    "downloadsCount": 12,
    "likesCount": 3
  }
}
```

### 3. 前端调用示例

```js
// 列表点击查看时: 先展示 thumbnailUrl, 再拉高清图
const detail = await bizWallpaperApi.bizWallpaperPublicDetail({ id })
// detail.imageUrl 为高清原图, detail.thumbnailUrl 为缩略图
```

## 四、壁纸下载计数（免登录）

> 前端点击「下载」时调用，使 `downloadsCount` 字段 +1（非事务强一致，允许最终一致）。

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/public/wallpaper/download?id={id}` | 无（免登录） | 指定壁纸下载次数累加 1 |

### 1. 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | String | 是 | 壁纸主键 |

### 2. 响应示例

```json
{ "code": 200, "message": "成功", "data": "下载计数已更新" }
```

### 3. 前端调用示例

```js
await bizWallpaperApi.bizWallpaperPublicDownload({ id })
// 成功后本地 downloadsCount + 1 即时反馈
```
