# 站点公开接口对接文档（免登录）

> 对应后端：`vip.xiaonuo.biz.modular.site.controller.BizSitePublicController`
> 路径前缀：`/public/site/**`，已在 `GlobalConfigure.NO_LOGIN_PATH_ARR`（即 `/public/**`）放行，**无需任何 token**，C 端 / B 端前台均可直接访问。

## 一、接口总览

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/public/site/categoryTree` | 无 | 获取分类树（可按模块筛选） |
| GET | `/public/site/identityList` | 无 | 获取身份列表（仅启用） |
| GET | `/public/site/identityCategoryTree` | 无 | 获取某身份下的分类树 |
| GET | `/public/site/page` | 无 | 网页分页（仅可见数据） |
| GET | `/public/site/detail` | 无 | 网页详情 |
| POST | `/public/site/click` | 无 | 网页点击量 +1 |
| POST | `/public/site/fetch` | 无 | 一键抓取网页卡片信息 |

> 返回结构统一遵循《后端响应规范》（`code` / `message` / `data` / `traceId`），分页字段见该规范的「分页」一节。

## 二、分类树 `categoryTree`

按模块返回分类的树形结构（含 `children` 子分类）。

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| module | String | 否 | 所属模块；为空返回全部模块的分类 |

**响应 `data`**：`BizSiteCategoryPublicVo` 数组（顶层为顶级分类，`children` 为子分类，递归嵌套）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 分类 ID |
| parentId | String | 父分类 ID，顶级为空 |
| name | String | 分类名称 |
| icon | String | 图标 |
| sort | Integer | 排序（升序） |
| module | String | 所属模块 |
| children | Array | 子分类集合（同结构） |

## 三、身份列表 `identityList`

返回所有「启用」状态的身份，用于前端身份维度的筛选 / 切换。

**请求参数**：无。

**响应 `data`**：`BizSiteIdentityPublicVo` 数组（已按业务默认顺序返回）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 身份 ID |
| identityName | String | 身份名称 |

## 四、身份下的分类树 `identityCategoryTree`

根据身份返回其关联分类构成的树（用途：切换身份后刷新分类导航）。

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| identityId | String | 是 | 身份 ID（见 `identityList`） |

**响应 `data`**：与「分类树」同结构的 `BizSiteCategoryPublicVo` 数组。

## 五、网页分页 `page`

公开分页查询，仅返回可见（`visible=true`）的网页，支持搜索、分类、身份、推荐、排序等筛选。

**请求参数（query / form 均可）**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| current | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 20（最大 100） |
| searchKey | String | 否 | 关键字，对 名称/描述/链接 模糊匹配 |
| categoryId | String | 否 | 分类 ID，级联包含其所有子分类 |
| identityId | String | 否 | 身份 ID，只返回该身份关联分类下的网页 |
| keyword | String | 否 | 关键词精准匹配 |
| recommend | Boolean | 否 | 是否只看推荐 |
| module | String | 否 | 所属模块 |
| sortField | String | 否 | 排序字段：`orderNum` / `count` / `createTime`，默认 `orderNum` |
| sortOrder | String | 否 | 排序方式：`ASC` / `DESC`，默认 `ASC` |

**响应 `data`**：标准分页对象，`records` 为 `BizSitePublicVo` 数组。

`BizSitePublicVo` 字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 网页主键 |
| name | String | 网页名称 |
| logo | String | LOGO（公开地址，可直接 `<img>`） |
| des | String | 描述 |
| link | String | 跳转链接 |
| count | Integer | 点击量 |
| visible | Boolean | 是否可见（Y→true / N→false，已转换） |
| recommend | Boolean | 是否推荐（Y→true / N→false，已转换） |
| background | String | 背景颜色 |
| cover | String | 封面（公开地址） |
| keyword | String | 关键字 |
| orderNum | Integer | 排序号，越小越靠前 |
| screenshot | String | 截图路径（公开地址） |
| module | String | 所属模块 |
| createTime | Date | 创建时间 |
| categoryList | Array | 所属分类集合（`BizSiteCategoryPublicVo`） |

> 说明：`visible` / `recommend` 已由后端的 `Y|N` 转换为布尔值，前端无需关心存储细节。

## 六、网页详情 `detail`

根据网页 ID 返回完整信息（结构与分页中的 `BizSitePublicVo` 一致）。

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | String | 是 | 网页主键 |

## 七、点击量 +1 `click`

前端「点击跳转」时调用，使该网页 `count` +1。

- 方法：**POST**（避免浏览器预取 / 爬虫误计数）
- 路径：`/public/site/click`
- 请求参数（query / form）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | String | 是 | 网页主键 |

- 响应 `data`：`"点击量已更新"`（字符串）
- 前端建议在用户真实点击跳转时调用一次，成功后本地 `count` 自增即可即时反馈（非强一致，允许最终一致）。

## 八、一键抓取卡片信息 `fetch`

传入一个网页链接，后端抓取并解析基础元信息（标题、描述、封面、LOGO、关键字），用于站点表单自动回填。

- 方法：**POST**
- 路径：`/public/site/fetch`
- 请求参数（query / form）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| link | String | 是 | 目标网页链接（需含协议，如 `https://...`） |

- 响应 `data`：`BizSiteFetchResult`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 网页名称 |
| des | String | 描述 |
| link | String | 链接（回传原 link） |
| cover | String | 封面 |
| logo | String | LOGO |
| keyword | String | 关键字 |

> 该接口处于 `/public/**` 免登录路径下，可前端裸 `fetch` 直接调用，适合站点表单「粘贴链接自动填充」场景。

## 九、对接约定

- 所有 `/public/site/**` 接口免登录，无需 token；图片类字段（logo / cover / screenshot）均为公开地址，可直接 `<img :src="url">`。
- 分类与身份数据来自后端，前端**不要写死**，应动态加载 `categoryTree` / `identityList` 渲染筛选项。
- 典型页面流：加载 `identityList` → 选身份加载 `identityCategoryTree` → 选分类用 `page` 拉列表 → 点击详情 `detail` + 调用 `click` 计数。
- 返回结构与分页字段遵循《后端响应规范》（同目录）。
